Towards Valid Student Simulation with Large Language Models#

Towards Valid Student Simulation with Large Language Models

Intro#

教育创新严重受限于真人参与，因此“学生模拟”非常关键

“学生模拟”已有很长历史，LLM逐渐用作模拟学生的底层

但是模型说的像学生，不代表其思考、学习过程像学生

  • 模型的表述虽然很自然，不一定符合真实学生的认知规律
  • 能力悖论：让一个知道答案的模型，表现为“尚未掌握知识的学习者”
    • 模型能力与学生状态不匹配：学生缺乏概念，而模型能够潜在调用相关知识

需要明确：学生当前知道什么、不知道什么，能使用哪些策略，以及接受教学后这些状态应当如何变化。

定义三个规范：

  • 能够获取什么？概念、策略、资源……
  • 为什么犯错？知识缺口、错误概念……
  • 状态如何变化？知识、策略的变化

两个组织维度：

  • 行为目标：想模拟学生的什么？学习过程、表现……
  • 环境：在什么环境下模拟谁

这决定了真实模拟是否有效

这段不只是说“LLM 有时模拟得不好”，而是在解释：问题出在生成行为缺少学习者状态的约束，因此解决方案也必须落实到状态及其变化机制上



Related#

传统学生模拟#

程序化一个错误模式，这种方法比较白箱，能够轻易看出学生为什么这么做

  • ACT-R：用来搭建“思考过程”的工具框架。

  • SimStudent、Apprentice Learner：能从示范、反馈中学习技能的系统。

但是研究者需要设计很多细节：分数计算还比较容易，模拟一个学生写作文、参与课堂讨论，就复杂得多

LLM#

LLM的出现让交互更为灵活

  • 直接扮演：主要靠提示词告诉模型“你是什么样的学生”。

  • 结合状态控制：明确记录“学生现在会什么”，约束模型回答，并规定教学后怎样更新。

但模拟的效度仍取决于对学习者状态与学习动态的明确规定

模型不一定会完全遵循当前的学习者状态，可能使用了超出学习者水平的知识



Formalizing#

学生模拟的评估#

根据能力悖论，LLM没法清除掉自己本身掌握的内容，因此可能会潜在影响后续的生成

因此必须考核三个内容：

  • 错误保真Fidelity of Error：给定一个target misconception，模拟器应在与之相关的问题类型上一致地应用它
  • 认知一致性Epistemic Consistency：生成的错误和解释应可因果地归因于所声明的认知边界，并在同构项目之间以及多轮互动中保持稳定，而不是表现为与专家推理之间的一次性表面偏差
  • 能力边界Boundary of Competence：在这些区域之外，模拟器仍应按照其假定的能力水平行事，避免既出现泄露不可及知识的专家捷径，又退化为随机噪声。（整体表现符合设定水平，不适用超出能力范围的方法）

前两个的区别：

  • 错误保真度看有没有复现指定错误（单次表现的层面）
  • 认知一致性看这些回答能否由同一个学习者状态解释（多次表现之间的层面）

模拟目标#

模拟学生之间不能一概而论，一起评价，而是需要根据：

  • 行为目标Behavioral Goals
  • 环境Environment
行为目标Behavioral Goals#
行为目标主要关心什么可以怎样理解
模拟表现某个时点的回答、正确率和错误模式给定这些题，这类学生会怎样答？
模拟学习接受教学后，能力如何随时间变化教了之后，学生怎样进步、遗忘或继续犯错？
模拟人类特征情绪、动机、人格和交互风格学生遇到困难时，会怎样参与互动？

这三类目标可以同时存在，作者不是要求每个系统只能选一种，而是要求研究者明确自己主要声称模拟了什么

  • 表现：模拟器能准确产生“当前水平学生常见的错误”
  • 学习：模拟“这些学生接受教学后如何变化”
  • 人类特征：学生不只是一个答题机器
环境Environment#
  • 学科
  • 学生群体与角色
  • 学习环境与交互的模态

总而言之，做学生模拟，必须声明：目标 × 环境

认知状态规范#

要求研究者说明：

学生当前能用什么知识？错误来自什么理解？接受教学后，状态按什么机制改变？

这篇大概了解一下就好

Agent4Edu: Generating Learner Response Data by Generative Agents for Intelligent Education Systems#

Agent4Edu: Generating Learner Response Data by Generative Agents for Intelligent Education Systems - AAAI 2025

Intro#

个性化学习可以针对学生历史的答题信息推荐新题

但是推荐新题的有效性取决于能否获取丰富的有效的高质量作答数据

  • 离线数据稀缺
  • 离线数据与在线练习之间可能存在gap

学生模拟作答提供了一定的帮助，但是：

  • 模拟过程过于简单：仅预测作答结果，没有充分利用解答过程
  • 依赖真实数据：现有方法仍然需要较多的真实数据，没有解决数据问题

大语言模型的zero-shot能力了极具前景

Method#

Learner Profile#

构造总体情况

  • 输入
    • 已做过的题、对应知识点、作答结果（对/错）
  • 输出
    • 活跃度：题目数
    • 多样性：知识点数
    • 正确率：比例
    • 偏好：知识点分布
    • 解题能力：IRT模型

前四项代码写死 即可完成统计

由于做的题不同，正确率并不能反映水平

  • 简单题高正确率
  • 复杂题低正确率

无法判断两者能力优劣


项目反应理论（Item Response Theory）的核心假设：学生答对一道题的概率，同时取决于学生能力和题目难度。

论文使用的公式是：

y^u,e=11+exp⁡[−(θu−be)] \hat y_{u,e} = \frac{1}{1+\exp\left [ -(\theta_u -b_e)\right ]} y^​u,e​=1+exp[−(θu​−be​)]1​
  • θu\theta_uθu​：学生uuu的能力
  • beb_ebe​：题目eee的难度
  • y^\hat yy^​：预测答对题目的概率

描述了能力相对难度，与答对概率的关系

难度相当（值为0），概率为50%

这里使用了真实的历史数据，去拟合了参数模型

最后将所有数值进行分档：

特征附录中的分档规则
活跃度根据全体学习者的中位数划分为高、低
多样性根据全体学习者的中位数划分为高、低
正确率将学习者按数值排序，按人数等分为低、中、高三组
能力将学习者按能力值排序，按人数等分为低、中、高三组
偏好直接保留最常练习的知识点名称

构造提示词：

你是一名在在线学习平台上自主练习的高中生。你的练习活跃度较低，练习不够规律，学习热情较低。你练习的知识类别较少，主要集中在有限的知识范围。你最常练习的知识点是几何。你的作答正确率较低，分析与解题能力一般。

Memory#

构造最近的情况

首先分为三类记忆

记忆类型保存什么作用
事实记忆已观察到的全部作答记录，以及每条记录的强化计数完整档案，供系统管理和筛选
短期记忆最近几条作答记录保留近期表现的细节
长期记忆反复强化的记录、知识熟练度、学习状态总结保留重要经历和概括性认识

Agent实际只读取整理后的短期记忆和长期记忆

Facts#

每一条新记录插入记忆（事实记忆）：

  • 做了哪道题、题目内容、知识点、答对还是答错
  • 强化计数器fff：初始值为1
    • 描述被几次相关练习强化过
    • RCD 的知识概念图工具：判断记录是否相关，不通过LLM
Short-Term#

更新短期记忆：

  • 设定s=5s=5s=5，取最近的sss​条数据即可
Long-Term#

这里是三类数据

  • 强化事实：fff超过一定阈值FFF的数据
  • 知识熟练度：通过DNeuralCDM估计学生在当前时刻，对不同知识点分别掌握到什么程度。
    • 例如：几何：good（0.7800）；函数：poor（0.2100）；……
    • 按当步学习者的数值排序，等比例划分高、中、低档。提示词使用 good / common / poor；缺少信息时可以写 unknown。
  • 学习状态：将学习者画像、短期记忆、长期记忆、上一次学习状态，送入LLM，输出

这里对于记忆有一个遗忘机制，当练习步数服从一个sigmoid函数超出阈值后，把这题从长期记忆中删除，fff设为1

Action#

“以这个学生当前的状态，面对这道题，他会怎么表现？”

输入来源提供什么信息
学习者画像画像模块整体能力、活跃度、正确率、偏好等
短期记忆记忆模块最近几次练习的题目与对错
长期记忆记忆模块强化记录、知识熟练度、学习状态总结
当前习题学习环境题目内容，以及可用的选项、参考答案、解析等
  • Task1：判断学生是否愿意做
    • Yes/No
  • Task2：学生能否识别考点
    • 两个干扰项一个正确答案
  • Task3：生成解题思路和最终答案
  • Task4：预测学生是否能做对Yes/No
