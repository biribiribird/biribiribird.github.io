IRT#

感觉得好好了解一下这个东西怎么做了，出现的次数非常多

判断一道题难度的方法是：准确率

但是这显然是高度与做题群体敏感的，如果群体是大学生、小学生，那么衡量难度就是完全不一样的

因此IRT考虑两个因素：

  • 学生能力
  • 题目难度

比较简单的模型，设定学生能力是θ\thetaθ，题目难度值是bbb
因此：

  • θ−b\theta - bθ−b越大，说明学生能力大于题目难度，做对的概率越高

一种常用的概率计算公式：

P=11+e−(θ−b) P = \frac{1}{1+e^{-(\theta-b)}} P=1+e−(θ−b)1​


这样当学生能力与题目难度相同时，做对的概率为50%


IRT从数据中进行学习

学生题目 A题目 B题目 C
小明对对对
小红对对错
小李对错错
小王错错错

显然对于这组数据：

  • 小明 > 小红 > 小李 > 小王
  • A < B < C

我们用这些数据去学习每个学生的参数θi\theta_iθi​，和每道题目bjb_jbj​


学生模拟估计试题难度的假设是：

  • 通过学生模拟生成作答，并且完成外部评分
  • 使用IRT模型进行拟合
  • 从而得到每个题目的难度参数

SMART: Simulated Students Aligned with Item Response Theory for Question Difficulty Prediction#

EMNLP 2025 - 2507.05129 SMART: Simulated Students Aligned with Item Response Theory for Question Difficulty Prediction

Intro#

  • 需求：估计题目难度
    • 传统方法：例如IRT，每个环节都依赖学生真实作答
  • 已有方法
    • 根据题目内容，预测输入题目文本，直接预测难度
    • 利用模拟学生，生成模拟作答，再根据作答结果估计难度
      • 根据作答结果估计难度的逻辑同IRT
  • 开放类型试题：简答题、编程题等……
    • 困难：回答生成的表达差异、回答的评分复杂

Q1：学生回答内容、表达方式多样

Q2：开放式回答评分复杂如何解决

Q3：如何解决生成表现不符合指定能力

形式化的，对于每道题iii：

  • 题目文本qiq_iqi​以及必要的附件mim_imi​
  • 评分标准wiw_iwi​

对于学生jjj：

  • 作答ri,jr_{i,j}ri,j​
  • 得分yi,jy_{i,j}yi,j​

Method#

  • 利用真实数据及其人工评分，学习一个LLM学生模拟器SSS
  • 模拟器SSS针对未见过的题目进行作答
  • 评分模型RRR进行打分
  • 根据完成评分的题目、学生拟合新的IRT模型，从而得到题目难度

学生模拟器的训练#

  • SFT
    • 输入：qi,mi,θjq_i,m_i,\theta_jqi​,mi​,θj​，组成提示词
    • 输出学生真实回答ri,jr_{i,j}ri,j​​

这里的θj\theta_jθj​是利用真实已有数据先拟合的

我们将θj\theta_jθj​四舍五入至小数点后四位，再转换为字符串。我们发现，这种做法优于将能力数值划分为带有文字描述的区间


但只是SFT的效果一般，模拟不同水平的学生效果一般

作者认为只通过SFT，没法很好学会从低能力和高能力学生的区别

因为只靠θ\thetaθ的数值去区分学生，SFT让模型偏好去靠题目和前文预测出回答中的许多词，从而降低损失，而通过θ\thetaθ去改变不同的分布，SFT应该做的不是很好

  • DPO：在给定学生能力和试题难度的条件下，优先选择得分具有更高 IRT 似然的回答

偏好对的构建：

  • 对于每个真实学生回答ri,jr_{i,j}ri,j​，我们找到同一道题iii的其他学生回答ri,kr_{i,k}ri,k​
  • 并且要求P(yi,j∣θj)−P(yi,k∣θj)>ϵP(y_{i,j}|\theta_j) - P(y_{i,k}|\theta_j) > \epsilonP(yi,j​∣θj​)−P(yi,k​∣θj​)>ϵ

就是这个学生回答ri,kr_{i,k}ri,k​且取得对应分数的概率，明显低于原回答

随机选取mmm个负例候选用于训练，构建 mmm个偏好对

相当于这部分数据更加注重了θ\thetaθ不同，所造成的回答质量的不同的这一区别

评分#

直接对真实数据进行SFT，输出一个分数

Result#

题目量少的时候（假设30题），学生模拟路线有一个好处：

  • 直接预测题目难度，最多30条数据
  • 学生模拟，可以30倍的题目

当训练题目少、但每道题有较多真实学生回答时，学生模拟能利用这些回答提供额外监督；在本文实验中，这条路线优于直接预测难度。


“Act Like a 5th Grader” is Not Enough: Bounding Knowledge in LLM-Based User Simulators#

“Act Like a 5th Grader” is Not Enough: Bounding Knowledge in LLM-Based User Simulators - 2608.30033 - EMNLP2026 Findings

Intro#

  • LLM无法遵循人物设定
    • 拥有近乎全知的广泛知识
    • 远超角色的推理能力

论文认为：当前基于大语言模型的用户模拟器主要依赖表层提示，缺乏对人类底层认知过程的显式建模

能力更强的模型，成绩反而更加集中。这支持了作者的判断——提升模型能力本身，并不保证提升模拟的真实性。

已有研究已经能用大模型模拟学生，包括根据学生的历史记录和能力画像生成回答、模拟课堂行为，以及复现特定错误

但这些方法往往需要额外的学生信息，关注的也多是个体行为、题目评估或某类错误

本篇论文的区别：

  • 输入只基于阅读材料和任务进行模拟
  • 目标对学生群体分布进行模拟，而非单个
  • 用工作记忆约束

Exp#

Pre-Exp · Prompt方法#

1You are simulating a 5th-grade student in Norway taking a
2reading comprehension test. Read the following text and
3answer the question as a typical 10-11 year old student would.
4The student may not always answer correctly.
5<TEXT> {text_content} </TEXT>
6<QUESTION> {question_text} </QUESTION>

同时使用

  • 平均准确率：答对题目的平均比例
  • JSD（Jensen–Shannon 散度）：比较模拟群体与真实评估群体的个人得分分布

显然差异极大

Random Guessing的JSD差异甚至更小

模型越强 做题能力越强 但反而更远离了人类

A Cognitively Bounded User Simulator#

教育理论基础：儿童的阅读理解受工作记忆容量限制，无法同时记住并整合全文信息。

  • Baddeley 的工作记忆模型：情景缓冲器暂存、整合信息，中央执行系统利用这些信息推理。
  • Cowan 解释容量：能同时保留的信息很有限；儿童的容量还在发展，因此更容易出现信息不够用的情况。

  • 一个参数化的容量上限CCC：定义了保存在工作记忆中的不同文本命题的最大数量

  • 策略

    • 单遍阅读：模拟器仅接收原文，并提取全文中最显著的CCC​ 个命题
      • 模拟学生只读一遍文章，随后尝试依靠这一份固定的记忆痕迹，回答所有后续问题的情形
    • 定向扫描： 模拟器同时接收原文和一道具体的阅读理解题，并提取最多CCC个它认为与该题最相关的不同命题

  • Step1：执行策略，提取CCC个命题
  • Step2：执行，将原始文本全部移除，要求执行模块使用命题回答

结构上分离信息提取与推理，严格约束了模拟器的全局注意机制

这里限制在英文阅读题上

试图通过不完整的信息进行推理，但这里似乎并没有办法去限制推理能力

指标分为两类：

  • 学生为中心：评估有多像学生

    • 平均准确率
    • JSD
    • 期望校准误差：评估不同离散难度区间内答对率的一致性

  • 题目为中心：评估模拟对题目难度的一致性

    • Spearman
    • Pearson

  • 显式建模认知边界能够有效缓解大语言模型的“超人偏差”
  • SPR 在所有以学生为中心的指标上都大幅优于 TS
  • TS 在以题目为中心的一致性方面表现最强

题外话：

  • 成绩分布：一个人答对多少
  • 难度相关性：一道题多少人答对

因此这里通过一个框架，没有多少变数的情况下，无法做出丰富的学生模拟

因此没法模仿群体学生？

说到底，它就是一个降低能力的旋钮，只是用工作记忆理论包装了一下。

PS2PS^2PS2: Parameterized Control for Fine-Grained Student Proficiency Simulation#

CIKM 2026 - 2602.00850 PS²: Parameterized Control for Fine-Grained Student Proficiency Simulation

Intro#

  • 传统方法
    • 依赖监督数据
    • 无监督依赖提示词控制学生模拟的层次
      • 文本提示词难以控制细粒度的能力差异，不同水平作答重叠，甚至低水平高于高水平
      • 文本变化难以保证模拟的一致性与可靠性
      • 学生能力往往通过分数衡量，而提示词方法无法可靠对应

作者认为：有效的能力模拟需要对认知能力的差异进行建模

  • 策略：参数化机制控制

    • 作者希望将成熟的大语言模型作为能力上界，加入参数化控制的噪声，降低能力

  • 需要关注的问题

    • Q1：性能下降缺乏方向
      • 降低的能力不可靠，最后输出的错误不一定是合理错误
    • Q2：衡量扰动幅度
      • 如何确定要施加多少噪声，降低多少能力？

Method#

Base Model#

首先训练一个下界大语言模型，作为低能力学生的基准

  • 待训练的模型：Llama3.2-1B-Instruct
  • 生成模型：GPT-4o
    • 根据题目、错误类型和风格示例，生成错误解答

错误类型：

  • 概念错误
  • 程序性错误
1错误分析：(程序性错误)
2学生知道面积等于长乘以宽，但在乘法计算中出现错误。
3
4错误解答：
5长方形面积等于长乘以宽。
66 × 4 = 28。
7
8最终答案：
928平方厘米。

1错误分析：(概念错误)
2学生可能混淆面积与周长，使用周长公式计算面积。
3
4错误解答：
5长方形面积等于长与宽之和的两倍。
6(6 + 4) × 2 = 20。
7
8最终答案：
920平方厘米。

流程：

  1. LLama生成初始回答
    • 输入：题目文本
    • 输出：LLama作答
  2. GPT-4o构造错误数据
    • 输入：LLama作答、题目文本、指定错误类型
    • 输出：gpt-4o的输出（实际操作中是两个输出，两个错误类型都输入一遍）
  3. 重复1、2，构造数据集
  4. Lora SFT

插值#

让“高水平模型”和“低水平模型”分别提出预测，再按比例合成一个预测

高水平模型（Llama3.2-3B-Instruct 或 Llama3.2-8B-Instruct ）和低水平模型对于同一上下文，输出的logits分别为zu,zlz^u,z^lzu,zl

定义参数ppp进行调控

z=(1−p)zl+pzu z = (1-p)z^l + pz^u z=(1−p)zl+pzu


混合 logits 后，通过 softmax 得到下一token的概率，进行输出

两个模型始终读取同一份已生成前缀

能力较准#

模拟40分、60分、80分的学生分别要用多大的p值

  • 有成绩单，使用不同p做同样的题，按照实际学生作答情况去校准
  • 无成绩单，直接0、0.25、0.5……

这里非常粗糙啊

Exp#

数据集

  • EEDI：学生对数学选择题的作答
    • 同时测试“有目标成绩”和“无目标成绩”
  • SciEntsBank：15个领域中197道科学问题的11,000条简答题回答
    • 未见领域（Unseen Domain，UD）
    • 未见问题（Unseen Questions，UQ）
    • 未提供成绩标注，只测试“无目标成绩”

RQ1#

模拟学生是否可以进行难度估计

  1. 能力较准，对不同程度的学生先设定好p值
  2. 根据p值对待测题目进行推理
  3. 评测
    • 选择题：直接验证正确性
    • SciEntsBank：原论文提供了训练验证模型的方法，进行打分

RQ2#

模型生成回答是否像学生

只采用SciEntsBank题目

  1. 生成回答
  2. 句子编码器 multi-qa-mpnet-base-dot-v1，把模拟回答和真实GT转化为向量
  3. 计算指标
    • MAUVE：两组回答的分布匹配程度
    • FID：两组回答在分布统计特征上的距离
    • Div. KL：两组回答的多样性分布差异

  • 回答的整体语义分布更接近真实学生
  • 回答的多样性也更接近真实学生

指标比较的是回答集合的分布

SciEntsBank 没有学生标识，因此它不能直接证明模型复现了某个具体学生持续、稳定的个人行为

RQ3#

学生水平能否被稳定控制

水平划分变细后，设置为高水平的学生，是否仍比低水平学生表现更好？

输入：

  • EDDI题目
  • 三种水平设置
    • 分成3级，让各水平模拟学生做题，统计每个水平的平均正确率
    • 分成5级，让各水平模拟学生做题，统计每个水平的平均正确率
    • 分成7级，让各水平模拟学生做题，统计每个水平的平均正确率

检查：

  • 随着设定水平提高，平均正确率是否也提高（单调性）
  • 增加水平数量后，各水平是否仍然能够区分

横轴：设定的学生水平
