Internet#

域名解决了IP地址不好记的问题
那么如何通过域名转化到IP地址呢？

  • Domain Name System（DNS）
    • 将域名和IP地址相互映射的一个分布式数据库（通讯录）
    • 一个域名可以对应多个IP，DNS可以轮流返回不同的IP，负载均衡
    • 层级结构
      • 根域名服务器：知道全球所有顶级域名的位置
      • 顶级域名服务器：管理.com 、.cn 、.org 等顶级域名

一次完整的DNS解析

  • 检查本地DNS缓存
  • 向本地DNS服务器请求
  • 本地DNS服务器
    • 本地DNS 询问 根服务器：返回.com
    • 本地DNS 询问 .com 服务器：返回example.com
    • 本地DNS 询问example.com ：得到IP地址
  • 缓存到本地

IP地址标记了一台服务器的位置
但是服务器可能有非常多服务，通过端口部署，开放多个

  • HTTP：默认80端口
  • HTTPS：默认443
  • SSH：22

Nginx#

linux下的目录是有约定俗成的习惯

  • /usr/bin：用户的可执行程序(binary)
  • /etc：软件配置文件
  • /var/www/：网站文件
  • /var/log：日志文件

/var 是 Variable（可变的）的缩写。它专门用来存放系统运行过程中经常变化的数据
