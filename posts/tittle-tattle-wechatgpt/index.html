Github Link

开始#

要求

  • Node.js >= 24.0.0
1npm install -g cli-wechat-bridge@latest

然后登录一下，输入：wechat-setup

扫码完成登录

然后我们尝试启动一下服务wechat-codex-start、wechat-claude-start、wechat-opencode-start

启动 bridge 后，建议先在微信里向 Bot 发送一条消息，例如 hello

这样 bridge 能拿到最新的微信会话 context_token，之后本地终端中的输入、最终回复和审批提示才能稳定同步回微信
